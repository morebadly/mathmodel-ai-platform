# B 版设计接入（2026-11-01）

设计基线为 PR #1 的独立原型。正式入口继续加载根目录 `app.js`、Django 账号与后端适配器，未加载设计目录的 M3、种子数据、演示验证码、客户端权限或模拟 AI/执行/解析结果。

## 接入范围

- 正式登录及学生、教师、管理员页面采用暖米色、深蓝、酒红色系、衬线标题、校园水彩与协会原会标。样式限定在 `data-mm-ui="academic"`，保留现有业务组件和窄屏导航。
- 增加亮色、暗色、跟随系统及单项语言轮换，支持左右箭头、键盘和横向滑动。偏好仅保存在本浏览器，不上传账号资料。系统外观变化会更新跟随模式。
- 语言切换只改变明确标记的系统文案，不重建表单、不保存业务记录、不修改输入值、文件名、资料名或用户正文。导航和主要账号/操作文案已接入三语；旧模块动态弹窗、说明和服务端错误仍有中文回退，不能视为全平台三语翻译完成或俄语专业审校通过。
- 详情页根据应用实际 `recordId` 排除用户标题与描述，包括旧式项目 URL。通用动作按钮保留原有 HTML/转义合同，用户附件名不进入系统文案翻译。
- Django 只额外开放三个界面文件和两张明确的 PNG；设计原型入口、原型运行脚本及私密目录继续不可公开访问。无数据库迁移、身份/权限/任务/提交/聊天/邮件/AI/沙箱接口变更。
- 独立原型另外修正跳转主内容、撤权后的资料选择过滤，以及系统词典与用户命名冲突时的用户文本保护。其余原型业务仍为演示，不代表正式服务。

## 本轮验证

- 独立临时 SQLite、内存缓存、本地邮件箱，禁用 dotenv 和外部网络：269 项后端测试，250 通过、19 因 PostgreSQL/Redis 条件跳过、0 失败或错误。新增静态资源测试覆盖真实入口、五个资源可达、原型脚本及私密路径不可达。没有将 SQLite 结果写成 PostgreSQL/Redis 验收。
- 用户 Edge，独立回环端口与合成账号：学生16、教师15、管理员12个主导航页均实际打开，标题/正文正常，无错误遮罩或文档横向溢出。三端控制台未见应用错误。
- 实际操作：邮箱密码登录、项目创建、阶段保存及刷新恢复、两份真实附件上传（含 `A&B.txt` 与 `知识中心.txt`）；切换中英俄及暗色后用户标题、笔记和附件名保持原样。
- 实际协作：教师发布团队任务，学生开始训练并保存阶段、提交V1快照，教师查看快照并退回反馈，学生刷新后看到反馈。两个 Edge 会话通过不同回环主机隔离登录，团队聊天双向无需刷新收发、学生 Enter 发送通过。
- 390×844 手机页面，以及1280、1440、1920宽度教师首页检查，无文档横向溢出。明暗组件覆盖登录状态、评语、聊天和编辑器。
- 本轮未消耗真实模型或 E2B 额度，未发外部邮件。原有真实服务适配与受限/待配置状态保留；本轮不据此重新宣称付费服务实测或生产并发验收。
