## 速度测量与结论

同一公网服务器、同一独立文稿、单页中文及公式，计时从请求提交至任务结束、释放确认及 PDF 下载完成；小样本受网络、调度和远端启动影响。

| 场景 | 公网端到端耗时 | 是否新执行远端编译 |
| --- | ---: | --- |
| 更新前同源基准 | 27.316 秒 | 是 |
| 更新后首轮同源基准 | 33.732 秒 | 是 |
| 更新后相同源码复用 | 3.642 秒 | 否，明确显示缓存 |
| 更新后小幅修改源码 | 17.067 秒 | 是 |

不能据此宣称首次完整 PDF 稳定提速；首轮甚至慢于原基准。实际改善是公式与常见正文在浏览器即时预览，无需等待完整 PDF；相同文稿可复用成功结果，日志和文件传输开销也已降低。完整 XeLaTeX 排版仍需远端服务，可能等待数十秒；复杂文档、并发高峰和更大样本未做性能承诺。

## 边界

自定义文档类、字体、宏包、图片和文献文件仍须满足真实 TeX 环境要求。正文辅助和即时预览不会将任意错误源码自动变成有效论文。原始稿、处理后的编译输入和真实 PDF 分开保留，修改稿件后继续展示旧 PDF 时会提示版本已旧。详见 [实现与适用范围](论文编译易用性20261104.md)。
