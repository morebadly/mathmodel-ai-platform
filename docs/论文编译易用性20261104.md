# 论文编译与公式修复（2026-11-04）

## 本轮行为

- 建模工作台第六阶段“论文撰写”可选择 LaTeX、Markdown 或普通文字。LaTeX 使用与写作工作室相同的真实隔离 XeLaTeX 编译服务，项目原笔记、其他阶段及文件均保留。
- LaTeX 可直接写正文，也可粘贴完整文档。正文自动补齐中文模板及常用数学宏包；完整文档按使用的常见命令补齐缺少的数学宏包。允许多行 documentclass 选项和整份源码外的 Markdown 围栏。
- 只对独立成行、括号完整的简单公式补齐数学环境；不会将行内说明文字或现有数学环境再次包装。文档与任务中的原始源码均保留，可分别导出原稿、本次可编译源码及 PDF。
- 增加行内、行间、分式、矩阵和求和按钮。正文与公式可即时预览，完整排版查看真正编译的 PDF；即时预览不等同于 TeX 全文编译。
- 真正编译失败时显示有界的远端日志、源码行号及定位按钮；上次成功 PDF 继续保留，并明确提示版本已旧。
- AI 导师历史回复按安全的 Markdown 与数学公式排版；用户原始问题和引用资料继续保留原文。

## 性能与隔离

- 新任务在数据库提交后立即通知 execution 队列，定时派发保留作后备。
- TeX 输入文件批量传输；日志缓冲后落库，降低远端请求和频繁写库开销。
- 同一账号、同一文稿、同一编辑区、相同源码、相同附件及编译配置在 24 小时内可复用成功 PDF。界面明确标记缓存，不声称产生了新的远端编译。
- 缓存复制成独立私有结果文件；当前账号、文稿及附件权限仍逐项检查。修改源码、附件哈希或编译配置会失效；不跨账号或跨文稿复用。
- 用户代码始终在远程隔离环境执行，不在 Django、Celery 或宿主机执行；保持禁网、禁 shell escape、资源限额、取消和释放机制。
- 未新增数据库结构、运行依赖、付费服务或长期驻留虚拟机。

## 适用范围

即时预览只转换常用正文命令及公式，图表、复杂布局、文献和定制宏以真实 PDF 为准。任意错误 LaTeX 不能保证自动修正；定制文档类、缺失字体、外部图片或宏包仍需要提供对应附件或运行环境。模板使用 Noto 中文字体，不能保证其他电脑的专有字体存在。

部署、附件/取消验证与公网性能测量在完成后另行补充回执，不将接口契约测试当作真实编译验收。
