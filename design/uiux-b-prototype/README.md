# MathModel AI · B版双端 UIUX 交付

此目录提供可直接评审的独立交互原型、校园素材、三语文案和开发接入说明。所有新增内容限定在本目录；正式平台的页面、后端、配置和数据均未修改。

## 查看原型

- 在线评审：[Sites 第3版](https://mathmodel-b-prototype.cdy6663.chatgpt.site)。本目录交互代码对应该版，仓库内另补充接入说明和检查证据。
- 本地：用浏览器打开本目录的 `index.html`，无需安装 Python、Node 或项目依赖。
- 需要 HTTP 预览时，从本目录运行 `python -m http.server 8786 --bind 127.0.0.1`，再打开 `http://127.0.0.1:8786/`。这是静态预览，不启动正式 Django 服务。
- 学生首页：`index.html#student/home`；教师首页：`index.html#mentor/mentor-home`。右上角切换演示角色。
- 三语预设示例：`index.html?lang=ru&theme=dark#mentor/mentor-home`。`lang` 支持 `zh/en/ru`，`theme` 支持 `light/dark/system`。

首次进入可直接查看演示数据。不要输入真实账号或密码；此处的登录、注册、验证码和找回流程都是演示。修改只保存在当前浏览器，使用顶部“重置演示”可恢复示例数据。

## 本轮设计内容

- B版温暖学术视觉：暖米色、深蓝、酒红；标题保留学术感，正文易读。产品名为 MathModel AI，会标沿用现有原图。
- 学生端16模块、教师端15模块，以及完整双端账号演示流程；管理员仅保留入口。模块详情、弹窗和状态不以导航数量计算，详见[模块与交付边界](模块与交付边界.json)。
- 中文、英文、俄文系统界面；用户正文、文件名、教师评语和来源保留录入语言。语言控件每次显示一种语言，左右滑动、箭头点击或方向键循环选择。
- 太阳、月亮、电脑图标分别选择亮色、暗色、跟随系统；沿用已有偏好保存。学生和教师首页展示完整校园水彩画，内页使用较轻装饰。
- 电脑端设计目标为1440×900、100%缩放，并检查1280/1920宽度。历史检查和本轮未完成项目分别列在[验证说明](VALIDATION.md)。

## 建议评审顺序

1. 教师创建任务、预览并发布，设置截止与补交规则。
2. 学生从教师任务新建或关联个人项目，提交成果快照。
3. 教师评阅、退回并设置重交截止；学生查看原反馈，手动加入个人修改清单，再提交新版本。
4. 检查个人与团队模拟竞赛的分工、共享、计时和锁定，以及知识、论文、文稿和工具模块。
5. 在双端检查语言、外观、空白、错误、无权限和保存失败状态。
