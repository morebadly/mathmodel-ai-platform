MathModel AI · 双端原型查看指南

本轮交付为独立交互原型。学生端16个模块、教师端15个模块共用演示数据，可切换中英俄界面与亮暗外观。采用B版温暖学术视觉，每个板块保留校园概念装饰，会标沿用原图。

阶段6校园插画与Sites整合

校园插画根据B版草图复原，属于概念装饰，并非学校官方插画。完整插画用于学生、教师首页，其他模块采用较轻装饰。本版保持演示功能、三语与明暗外观；文件检查通过不代表浏览器视觉验收。

从哪里开始

打开同目录的index.html。右上角切换“学生端 / 教师端”、语言和外观。直接打开原型默认进入教师总览。顶部评审栏可模拟空白、加载失败、无权限和保存失败，完成后切回正常。

以1440×900、浏览器缩放100%审阅；阶段4/5曾检查1280和1920宽度；阶段6插画修订的实际渲染检查尚待完成。仅验收电脑端。侧边导航可以向下滚动，完整查看全部模块。

建议先走完这条路径

  1. 教师端 → 训练任务 → 创建任务，保存草稿，再预览并确认发布。
  2. 学生端 → 训练中心 → 打开刚发布的任务 → 新建项目或关联未关联任务的个人项目。
  3. 建模工作台 → 编辑八阶段笔记并先保存 → 确认提交成果快照。未保存文字不进入快照。
  4. 教师端 → 提交与反馈 → 查看对应版本，保存教师草稿或预览并发布反馈。退回修改时设置独立重交截止；评分可留空。
  5. 学生端 → 查看反馈 → 手动加入私人修改清单，可自勾及记录个人备注。这些内容不直接共享给教师，自勾不等于教师认可。
  6. 保存修改，再填写重交说明并提交新版本。新版本不覆盖旧提交。教师按版本复核，已评阅不自动等于通过。

其它重点路径

  • 团队：教师创建团队和邀请；学生在“我的账号”明确接受。教师移出成员后，撤销该团队访问；仍在别的团队不继承原任务查看权。
  • 资料：个人资料默认私有；明确选择资料后才生成团队共享副本。教师只看主动提交的附件快照，不从学生私人文件库补取正文。
  • 成绩导入：六列CSV文本粘贴，先预览与校验，确认时再校验。完全重复跳过；冲突阻止整批导入，不自动覆盖。模板为演示数据。
  • 邮箱提醒：手动确认和计划均为模拟；执行前复核任务/团队权限、邮箱验证与接收意愿，逐人显示成功或跳过原因。关闭页面后不在后台执行，返回时再检查到期计划。
  • 论文与写作：原件不变，创建关联文稿；可保存草稿、命名版本，确认后导出纯文本或关联成果快照。原型不生成真实Word/PDF排版文件。
  • 模拟竞赛：可做个人或团队，队长邀请演示成员并分工，切换评审身份演示接受邀请、更新自己分工与讨论。关闭或离线不暂停计时，到时锁定已保存成果；结束后可复制为个人练习。

三语与明暗的边界

中英俄翻译覆盖系统导航、按钮、表单、状态、提示和已走查的动态弹窗。教师评语、正文、项目名称、资料名称和来源保留原语言，不自动改写。全部采用左到右布局；日期在原型中按北京时间显示。语言切换保留本会话未保存的项目笔记、文稿及教师评阅输入。

标题保留学术感衬线字体，正文使用系统可用的清晰无衬线字体。没有捆绑或下载商业字体，实际字形取决于本机字体。俄语已做界面与术语一致性检查，尚无母语者专业审校记录，正式发布前应补做。

演示账号与数据

只使用@example.invalid演示邮箱，演示密码输入任意六位以上文字，不输入真实密码。验证码为123456，教师注册页的固定演示值为TEACH-DEMO；这些均不是正式凭证。管理员只保留入口说明。

演示数据保存在浏览器本地。右上角角色切换只是同一份演示数据的视图切换，用于评审权限边界；正式产品必须由后端实现鉴权与数据隔离。我的账号支持导出和重置演示数据。浏览器清理数据或更换浏览器后，原记录可能不可用。请把整个目录保留在一起。
